# Jira и Confluence

Оба живут на одном сайте `molvi.atlassian.net` и доступны через MCP-сервер
`jira-confluence`, настроенный для этой рабочей копии.

|                        |                                                              |
| ---------------------- | ------------------------------------------------------------ |
| Задачи, эпики, спринты | Jira, проект **MOL**                                         |
| План, дизайн, решения  | Confluence, пространство **MOL**, корень — страница `294930` |
| Продуктовый план       | страница `327681`                                            |

## Чего MCP не умеет

Сервер создаёт, читает, правит, двигает по статусам и комментирует задачи, ищет по JQL —
этого хватает для обычной работы. Он **не** проставляет родителя и спринт и не администрирует
сайт. Это делается через REST теми же учётными данными, которые уже лежат в конфигурации MCP
этой копии.

**Оценку он всё-таки пишет** — проверено 20.09.2026 на MOL-52: `jira_update_issue` с
`fields: {"customfield_10016": 9}` записал её, а `jira_search` по
`"Story point estimate" = 9` это подтвердил. Здесь раньше было написано обратное.

|                       |                                                 |
| --------------------- | ----------------------------------------------- |
| Доска                 | `2`                                             |
| Спринт                | `customfield_10020`                             |
| Оценка в сторипоинтах | `customfield_10016`                             |
| Родитель (эпик)       | поле `parent`, по ключу                         |
| Типы задач            | Эпик, История, Задача, Баг — сайт русскоязычный |

## Три ловушки, на которые уже наступили

- **Параметр задачи называется `issueIdOrKey`**, а не `issue_key` и не `issue_id_or_key`.
  С неверным именем сервер отвечает «Issue ID or key must not be empty» — то есть жалуется
  на пустое значение, а не на незнакомый параметр, и это уводит в сторону.
- **`/rest/api/2/search` удалён** и отвечает `410`. Использовать `/rest/api/3/search/jql`.
- **Удаление проекта отправляет его в корзину**, и она продолжает держать имя и ключ.
  Чтобы освободить их, удалить повторно с `enableUndo=false`.

## Новая рабочая копия

MCP-сервер настраивается на уровне каталога и не приезжает вместе с клоном. Без него
сессия не прочитает ни план, ни задачи. Добавляет владелец — токен вставляет он сам:

```bash
claude mcp add jira-confluence \
  --env ATLASSIAN_URL=https://molvi.atlassian.net \
  --env ATLASSIAN_EMAIL=<почта> --env ATLASSIAN_API_TOKEN=<токен> \
  -- npx -y mcp-jira-confluence
```

Область — `local`, она по умолчанию. Пользовательская область столкнулась бы с рабочим
сайтом Atlassian, настроенным для других проектов на этой же машине.
