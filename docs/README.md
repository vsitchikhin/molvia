# Где что лежит

Проект живёт в трёх местах, и это разделение намеренное.

| Что                               | Где                              | Почему там                                                                        |
| --------------------------------- | -------------------------------- | --------------------------------------------------------------------------------- |
| Правила разработки                | `CLAUDE.md` в этом репозитории   | Меняются вместе с кодом и должны ревьюиться в том же коммите                      |
| Продуктовый план, дизайн, решения | Confluence, пространство **MOL** | Не следуют за кодом и обязаны пережить потерю диска: там версии и резервные копии |
| Задачи, эпики, спринты            | Jira, проект **MOL**             | Трекер                                                                            |

## С чего начать новой сессии

| Файл                 | О чём                                                                                |
| -------------------- | ------------------------------------------------------------------------------------ |
| `docs/onboarding.md` | Что за продукт, что уже сделано, откуда брать работу, какие решения не переоткрывать |
| `docs/tracker.md`    | Jira и Confluence: чего не умеет MCP, идентификаторы полей, ловушки                  |
| `CLAUDE.md`          | Правила: архитектура, границы слоёв, деньги, тесты, коммиты                          |

## Ссылки

- **Продуктовый план** — https://molvi.atlassian.net/wiki/spaces/MOL/pages/327681
  Полный план с обоснованием каждого решения: ниша, модель данных, нарезка релизов
  по гипотезам с порогами провала, деньги, техника, название, риски.
- **Корень документации** — https://molvi.atlassian.net/wiki/spaces/MOL/pages/294930
  Под ним бриф для дизайна и хендофф 0.1: экраны, токены, инвентарь компонентов,
  открытые вопросы.
- **Трекер** — https://molvi.atlassian.net/jira/software/projects/MOL

Читать и править всё это можно не только руками: в рабочей копии настроен MCP-сервер
`jira-confluence`, привязанный к этому же сайту. Он подключается на уровне каталога, так
что рабочие проекты с другими аккаунтами он не задевает.

## Что вне репозитория

`.scratch` — симлинк на `../_shared/molvia/scratch`, общий на все рабочие копии и вне
гита. Там лежит выгрузка от Claude Design: кликабельный прототип, 14 скриншотов в двух
схемах, исходные токены. Это замороженный артефакт поставки — его не правят, а читаемые
копии текстов из него есть в Confluence.

**Планов задач там больше нет.** План пишется комментарием к самой задаче в Jira: сначала
требования, потом план, потом апрув владельца, и только затем код. План в файле отстаёт
от задачи и не виден из других рабочих копий.
